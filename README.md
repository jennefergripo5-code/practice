# Simple Website

A simple and responsive website created using **HTML, CSS, and JavaScript**. This project is made for practice and learning basic web development.

## 📌 About the Project

This website demonstrates the basic structure of a website, including navigation, content sections, styling, and simple interactions.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
simple-website/
│
├── index.html
├── about.html
├── contact.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the website.

## ✨ Features

* Simple navigation menu
* Responsive design
* About section
* Contact page
* Basic JavaScript interactions
* Clean and simple layout

## 🎯 Purpose

This project is created to practice the fundamentals of web development and learn how HTML, CSS, and JavaScript work together.
